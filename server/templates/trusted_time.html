How the status is established

The host-side monitor reads only the approved Chrony tracking and source status. The application validates the protected configuration digest, source quorum, synchronization age, offset and uncertainty.

NTS authentication is inferred from the protected NTS-only configuration, authselectmode=require and the selected source quorum. The unprivileged monitor does not query Chrony's privileged authdata command. This limitation is intentionally shown here.
