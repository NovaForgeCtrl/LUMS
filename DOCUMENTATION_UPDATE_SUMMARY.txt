  - 5-second collection interval
  - 7-day data retention

Dashboard Access:
  - Permission requirements (clients.view)
  - Dashboard features and metrics
  - Client status classification
  - Fleet filtering capabilities
  - Chart views (line, area, donut)
  - Historical data ranges

Installation:
  - Step-by-step client setup
  - Telemetry agent installation (agent/telemetry.py)
  - Systemd units (service + timer)
  - Environment variable configuration:
    * LUMS_BASE (server URL)
    * LUMS_TOKEN (authentication)
    * LUMS_CA_FILE (optional CA certificate)
  - Timer enablement command

Database Migration:
  - Server-side migration requirement
  - Command: python3 server/security_migration.py
  - Prerequisite for network data submission
  - Telemetry_samples table schema

Status Thresholds:
  - Online: ≤120 seconds since last report
  - Unknown: 120-600 seconds or invalid timestamp
  - Offline: >600 seconds
  - Explanation of reporting recency vs. health

Data Retention:
  - 7-day automatic removal
  - History query limitations (1-168 hours)
  - Downsampling to 1,000 samples maximum
  - 5-second dashboard refresh interval

Troubleshooting:
  - No samples appearing (URL, token, timer status, logs)
  - TLS certificate errors (self-signed, CA configuration)
  - High memory/CPU reported (calculation details)
  - Systemctl and journalctl diagnostic commands
