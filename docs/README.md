# LUMS Localized Beginner Guides

The root-level Markdown guides are the English source of truth. The guides
linked below are concise, translated introductions for people who are new to
LUMS or Linux. They cover the basic concepts, safe first steps, and where to
find detailed instructions; they are not complete translations of every
technical procedure.

When a localized guide and an English technical guide differ, follow the
current English source guide and its version-controlled procedures. Please
report outdated translations so they can be updated with the source
documentation.
