# LUMS 快速入门 — 简体中文

本指南面向刚开始使用 LUMS 或 Linux 的用户。它不是所有技术手册的完整
翻译；详细项目文档以英文维护。[语言索引](../../README.md)。

## LUMS 是什么？

LUMS 用于集中管理 Linux 计算机。服务器显示客户端、已安装软件和可用
更新。每台受管计算机上的 Agent 会调用本机软件包管理器执行已批准的操作：
Debian/Ubuntu 使用 APT，Arch Linux 使用 pacman。LUMS 不会自动安装所有
更新。

## 如果你只是使用 LUMS

打开管理员提供的网址，并使用自己的账户登录。你能执行哪些操作取决于
账户权限。不要与他人共用账户，也不要分享客户端令牌。可以在登录页右上角
选择语言；登录后，LUMS 可以将语言偏好保存到你的账户。

## 安装与运维

测试通过不代表生产服务器已经安装完成。安全的生产环境还需要 HTTPS、
妥善保护的应用密钥、持久化数据库存储以及经过验证的备份。服务器和
Linux 客户端需要分别配置。请仔细阅读[英文安装指南](../../../install.md)；
执行命令前，先将 `LUMS-SERVER` 等占位符替换为实际值，并核对所有路径。
如果 LUMS 已在运行，请使用[管理指南](../../../administration.md)中的升级
步骤，而不是首次安装步骤。

正常升级时，切勿删除 Docker 卷 `lums-data`，因为数据库保存在其中。
保留现有的密钥和备份挂载，以及容器安全选项。示例命令不适用于所有环境；
先与当前运行的容器配置核对。

## 出现问题时的第一步检查

在服务器上，以下命令可以查看容器状态、近期应用日志和 Nginx 状态：

```bash
sudo docker ps -a --filter name=lums
sudo docker logs --tail 100 lums
sudo systemctl status nginx --no-pager
sudo nginx -t
```

`sudo` 可能会要求输入 Linux 密码。这些检查不会更改配置。不要一开始就
删除数据库或 Docker 卷、以特权模式启动容器或关闭安全选项。分享日志前，
请删除密码、令牌、密钥和个人信息。
