# LUMS 基础设施拓扑

## 目的

经过身份验证的 `/infrastructure` 页面将已注册的 LUMS 客户端和手动维护的基础设施整合到一个依赖关系视图中。它是资产清单和关系图，并非自动网络发现或配置管理系统。

## 数据来源与归属

- 已注册的 LUMS 客户端从现有客户端注册表读取，并自动显示其报告的主机名、IP 地址、操作系统及启用／报告状态。已禁用的客户端仍会显示，以便理解现有关系。这些条目在拓扑页面中为只读；请通过常规客户端管理流程管理客户端。
- 服务器、虚拟机、容器、网络设备、服务和存储可以手动录入，并提供主机名、IP 地址、角色、位置和备注。
- 关系由人工维护。支持的类型为 `depends on`、`hosts`、`connects to` 和 `runs on`。
- 页面不会扫描子网、查询云 API，也不会从服务或容器配置推断依赖关系。请保持手动录入的资产和关系为最新状态。

## 访问控制与审计

拥有 `clients.view` 权限的用户可以查看拓扑。只有拥有 `infrastructure.manage` 权限的管理员才能创建、编辑和删除手动条目或关系。更改需要使用应用程序的常规已验证会话、CSRF 保护和审计日志记录。

`infrastructure.manage` 依赖 `users.manage` 和 `clients.view`，并由 `016-infrastructure-topology` 数据库迁移授予管理员。删除手动管理的节点也会删除其关系记录。删除客户端会删除引用该客户端的关系。

## 阅读关系图

关系图按类别排列节点，并使用带方向的边绘制每条已记录关系。**共享依赖项**是指至少有两个其他节点通过 `depends on` 指向的节点。这是识别潜在中心故障点的有用线索，但并非完整的可用性或影响分析。关系图不会考虑冗余、故障转移、容量、网络分段或未记录的依赖关系。

要查看准确的主机名、IP 地址、角色、位置和关系详情，请使用资产清单表和关系表。拓扑页面使用当前选定的 LUMS 主题，并与共享的可折叠侧边栏配合使用。英文原文：[LUMS Infrastructure Topology](../../../LUMS_Infrastructure_Topology.md)。
