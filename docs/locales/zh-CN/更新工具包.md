# 可下载的更新工具包

`main` 上的 `Tests` 工作流通过后，`Updater package` 工作流会创建 `lums-update-tools-<commit>.tar.gz` 构件和 SHA-256 校验和。请从该成功工作流运行的 **Artifacts** 部分下载；构建构件会保留 90 天。

发布 GitHub Release 时，工作流会先针对发布标签运行测试套件，然后附加 updater 归档和确定性源代码归档。源代码归档包含 SHA-256 校验和及经过测试的提交标识；只有在三个源代码验证资源全部就绪后，Update Center 才会列出该版本。

updater-tools 软件包是便捷下载内容，不是 Debian 软件包。Web 容器不会直接安装源代码归档。在单独安装的主机 updater 通过部署检查，并针对该确切部署验证数据库备份和回滚行为之前，不要使用它更新生产环境。英文原文：[Downloadable update-tools package](../../update-tools-package.md)。
