# LUMS — 管理ガイド

> **ノイズのない Linux アップデート管理。**

本ガイドは、サーバーとクライアントがインストールされた後の LUMS の日常的な管理と運用について説明します。

LUMS Web インターフェースを通じて実行される管理タスク、および LUMS サーバーと管理対象クライアント上での制御された運用タスクに焦点を当てています。

インストール手順は[インストールガイド](インストールとアップグレード.md)に記載されています。

トラブルシューティング手順は[トラブルシューティングガイド](トラブルシューティング.md)に記載されています。

セキュリティアーキテクチャと監査情報は[セキュリティモデル](セキュリティモデル.md)に記載されています。

> このファイルは日常管理の概要です。詳細なバックアップ、復元、アップグレード手順の日本語訳は未完了です。本番環境を変更する前に、[英語の管理ガイド](../../../administration.md)と[データベース復元手順](../../../server/static/backup-restore.md)を確認してください。

## はじめに：日常管理

本ガイドは、既存の LUMS インストールの責任者向けです。詳細な技術セクションは英語で維持されています。まず以下の用語を確認してください：

* **ユーザーアカウント：** ある人物が LUMS Web インターフェースで何を実行できるかを決定します。アカウントを共有しないでください。各人に個別のアカウントを付与してください。
* **クライアント：** 管理対象の Linux コンピューター。そのクライアントトークンはシークレットであり、Web アカウントのパスワードとは異なります。
* **更新ジョブ：** エージェントが取得し、対象コンピューター上で APT または pacman を使用して実行する要求された操作。開始する前に、対象とパッケージを確認してください。
* **バックアップ：** データベースの独立した検証済みコピー。同じ Docker ボリューム内のコピーは、そのボリュームの喪失から保護しません。
* **アップグレード：** コンテナのバージョンを置き換え、データベースは置き換えません。通常のアップグレードでは `lums-data` を削除したり再作成したりしてはなりません。

### 変更前の安全チェックリスト

1. 更新ジョブが実行中かどうか、およびメンテナンスウィンドウが必要かどうかを確認します。
2. 最近の使用可能なデータベースバックアップが存在することを確認します。
3. 実行中のイメージ、コンテナ設定、データパスを記録します。
4. アクティブなコンテナを停止する前に、新しいイメージをビルドしてテストします。
5. 同じデータ、シークレット、バックアップマウント、および同じセキュリティオプションでコンテナを置き換えます。
6. 起動後のコンテナステータス、ログ、HTTPS サインイン、データを確認します。
7. 新しいバージョンが検証されるまで、古いコンテナをロールバックオプションとして保持します。

**実行しないでください：** `docker volume rm lums-data`、`docker system prune --volumes`、または通常のアップグレードの一部としてのその他の削除コマンド。これらはデータを永久に削除する可能性があります。どのコンテナまたはパスがアクティブかわからない場合は、停止して最初に現在の設定を確認してください。確認せずにサンプルコマンドをコピーしないでください。

## 1. 管理の概要

LUMS は、Linux ソフトウェアインベントリ、利用可能な更新、パッケージ操作、更新ジョブ、管理対象クライアント、ユーザー、および運用履歴の集中管理を提供します。

管理インターフェースは、3 つのロールテンプレートを提供します：

* **Administrator**
* **Operator**
* **Viewer**

アカウントが作成されると、選択されたロールが推奨される権限セットを自動的に設定します。管理者はこれらの権限をユーザーごとに調整できます。ロールラベルではなく、保存された権限がアクセスを決定します。

LUMS はまた、サーバー側の管理操作をクライアント側のパッケージ実行から分離します。

通常の運用フローは次のとおりです：

```text
Administrator / Operator
        │
        ▼
   LUMS Web UI
        │
        ▼
     LUMS API
        │
        ▼
      SQLite
        │
        ▼
   Managed Client
        │
        ▼
 APT / pacman / system
        │
        ▼
      Result
        │
        ▼
     LUMS API
        │
        ▼
      SQLite
        │
        ▼
    Web Interface
```
