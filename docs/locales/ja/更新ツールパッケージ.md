# ダウンロード可能な更新ツールパッケージ

`main` で `Tests` ワークフローが成功すると、`Updater package` ワークフローが `lums-update-tools-<commit>.tar.gz` アーティファクトと SHA-256 チェックサムを作成します。成功したそのワークフロー実行の **Artifacts** セクションからダウンロードしてください。ビルドアーティファクトの保持期間は 90 日です。

GitHub Release が公開されると、ワークフローはリリースタグに対してテストスイートを実行してから、updater アーカイブと決定的なソースアーカイブを添付します。ソースアーカイブには SHA-256 チェックサムとテスト済みコミット識別子が含まれます。ソース検証用の 3 つのアセットがすべて揃ってから、Update Center にリリースが表示されます。

updater-tools バンドルは利便性のためのダウンロードであり、Debian パッケージではありません。ソースアーカイブは Web コンテナーに直接インストールされません。別途インストールしたホスト updater がデプロイメント検査に合格し、そのデプロイメントでデータベースのバックアップとロールバック動作の両方を検証するまでは、本番環境の更新に使用しないでください。原文は[英語の更新ツールパッケージガイド](../../update-tools-package.md)です。
