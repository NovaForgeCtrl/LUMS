# LUMS プロジェクト概要

**Linux Update Management without the noise.**

LUMS（Linux Update Management Server）は、Linux クライアントのソフトウェア情報や更新状況を一元的に確認し、承認されたパッケージ操作を管理するためのサーバーです。操作結果を記録し、管理者が何を実行したかを追跡できるようにします。

## 構成

LUMS は管理サーバーと、管理対象の各 Linux コンピューター上で動作するエージェントで構成されます。

```text
管理者のブラウザー
        │ HTTPS
        ▼
  LUMS サーバー ─── SQLite データベース
        │ HTTPS / API
        ▼
Linux クライアント上の Agent / Watcher
        │
        ▼
APT / pacman
```

サーバーは Web インターフェース、API、認証、権限管理、ジョブ管理、監査ログ、永続データを提供します。クライアントの Agent はパッケージ情報を報告し、Watcher と連携して承認された更新ジョブを実行します。

## 主な機能

* 登録済みクライアントと個別のクライアント認証情報を管理する
* インストール済みソフトウェアと利用可能な更新を確認する
* パッケージのインストール、削除、更新を管理する
* 更新ジョブの状態と実行結果を記録する
* ロールベースの権限と監査履歴を利用する
* オプションで CPU・メモリーのテレメトリーを表示する

対応するパッケージ管理系統は Debian / Ubuntu の APT / dpkg と、Arch Linux の pacman です。LUMS はこれらのパッケージマネージャーを置き換えず、管理レイヤーとして利用します。

## 運用上の注意

テストに成功したことや Docker イメージをビルドできたことだけでは、本番運用の準備が整ったことにはなりません。本番環境では HTTPS、保護されたアプリケーションシークレット、永続データ、独立した検証済みバックアップ、コンテナの適切な制限が必要です。復元可能なバックアップを定期的に確認してください。
