# LUMS クイックスタート — 日本語

このガイドは、LUMS や Linux を初めて使う方向けの簡易ガイドです。技術
マニュアル全体の翻訳ではありません。詳細なプロジェクト文書は英語で管理
されています。[言語一覧](../../README.md)。

## LUMS とは？

LUMS は Linux コンピューターを一元管理します。サーバーではクライアント、
インストール済みソフトウェア、利用可能な更新を確認できます。各クライ
アント上の Agent は、そのコンピューターのパッケージマネージャーを使って
承認済みの操作を実行します。Debian/Ubuntu では APT、Arch Linux では
pacman を使用します。LUMS がすべての更新を自動でインストールするわけ
ではありません。

## LUMS を利用するだけの場合

管理者から案内された Web アドレスを開き、自分専用のアカウントでログイン
してください。利用できる操作はアカウントの権限によって異なります。
アカウントやクライアントトークンを他人と共有しないでください。ログイン
ページ右上で言語を選択できます。ログイン後、言語設定がアカウントに保存
される場合があります。

## インストールと運用

テストの成功だけでは、本番サーバーのインストールが完了したことにはなり
ません。本番環境には HTTPS、保護されたアプリケーション秘密鍵、永続化
されたデータベース、検証済みバックアップなどが必要です。サーバーと
Linux クライアントは別々に設定します。[英語のインストールガイド](../../../install.md)
を順に確認してください。`LUMS-SERVER` などのプレースホルダーを実際の
値に置き換え、コマンドを実行する前にパスを確認してください。すでに
LUMS が稼働している場合は、初回インストールではなく
[管理ガイド](../../../administration.md)のアップグレード手順を使います。

通常のアップグレードで Docker ボリューム `lums-data` を削除してはいけ
ません。データベースが保存されています。既存の秘密情報・バックアップの
マウントとコンテナーのセキュリティ設定も維持してください。例のコマンド
をそのまま使わず、現在のコンテナー設定と照合してください。

## 問題が起きたときの最初の確認

サーバーで次のコマンドを実行すると、コンテナーの状態、最近のアプリケー
ションログ、Nginx の状態を確認できます。

```bash
sudo docker ps -a --filter name=lums
sudo docker logs --tail 100 lums
sudo systemctl status nginx --no-pager
sudo nginx -t
```

`sudo` は Linux のパスワードを求める場合があります。これらの確認では
設定は変更されません。最初にデータベースや Docker ボリュームを削除したり、
コンテナーを特権モードで起動したり、セキュリティ設定を無効にしたり
しないでください。ログを共有する前に、パスワード、トークン、鍵、個人
情報を取り除いてください。
